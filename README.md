# برنامه هفتگی کلاس‌ها (نسخه‌ی ری‌اکتی)

یک `PWA` با `React` و `Vite`: برنامه‌ی هفتگی، کلاس بعدی، تشخیص خودکار هفته زوج و فرد، و امتحانات با تایمر.

## اجرا روی کامپیوتر

```
npm install
npm run dev
```

برای ساخت نسخه‌ی نهایی: `npm run build` (خروجی در پوشه‌ی `dist`).

## ساختار پروژه

- `src/data/courses.js` برنامه‌ی کلاس‌ها (برای تغییر برنامه فقط این فایل)
- `src/data/exams.js` برنامه‌ی امتحانات (تاریخ شمسی)
- `src/utils/` توابع کمکی: تبدیل تاریخ شمسی، تشخیص هفته زوج و فرد، کلاس بعدی، تایمر امتحان
- `src/components/` اجزای کوچک: نوار تب، اعلان، ردیف کلاس، کارت کلاس بعدی و ...
- `src/pages/` چهار صفحه‌ی برنامه
- `src/styles/` فایل‌های `CSS` جدا: رنگ‌ها، پایه، اجزا، نوار تب و اعلان

## انتشار روی GitHub Pages

روش خودکار: فایل `.github/workflows/deploy.yml` را همراه پروژه آپلود کن، سپس در `Settings` بخش `Pages` گزینه‌ی `Source` را روی `GitHub Actions` بگذار. با هر `push` سایت خودش ساخته می‌شود.
